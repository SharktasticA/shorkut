# SHORKUT

SHORK UPTIME (SHORKUT) is a small utility that prints the system uptime in the same format as `/proc/uptime` without needing `/proc` to be mounted. It is designed for SHORK Operating Systems like [SHORK 486](https://github.com/SharktasticA/SHORK-486) and their init script, able to be used early in its process. The idle time component is only a `0.00` placeholder at this time.
